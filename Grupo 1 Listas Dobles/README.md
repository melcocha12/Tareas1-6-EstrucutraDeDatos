# Estructuras de Datos en C++

Repositorio que contiene 6 ejercicios de estructuras de datos desarrollados en C++.

## Contenido

1. **Listas Dobles:** operaciones con listas doblemente enlazadas.
2. **Listas Dobles Circulares:** manejo de listas circulares.
3. **Pilas:** implementación de estructuras LIFO.
4. **Colas:** implementación de estructuras FIFO.
5. **Notaciones:** conversión y evaluación de expresiones matemáticas.
6. **Recursividad:** operaciones recursivas y manejo de pilas.

## Compilación y ejecución

**Requisitos:** tener instalado `g++` (MinGW-w64 o GCC).

Abrir una terminal PowerShell en la carpeta principal del repositorio.

### Grupo 1: Listas Dobles

```powershell
cd "Grupo 1 Listas Dobles"
g++ *.cpp -o programa.exe
.\programa.exe
cd ..
```

### Grupo 2: Listas Dobles Circulares
